# 安全策略

## 支持版本

| 版本 | 支持状态 |
|:--|:--|
| 1.x.x | ✅ 当前支持 |

## 报告漏洞

{: .warning }
**请不要在公开 Issue 中报告安全漏洞。**

请通过以下方式私下联系维护者：

1. 发送邮件至 **security@lessup.org**
2. 在仓库 Security 标签页中创建安全公告

报告中请包含：
- 漏洞描述与影响范围
- 复现步骤
- 受影响的版本
- 可能的修复建议（如有）

## 处理流程

| 阶段 | 时间 |
|:--|:--|
| 确认收到 | **48 小时内** |
| 评估与制定修复计划 | 1 周内 |
| 发布补丁 | 视严重程度而定 |
