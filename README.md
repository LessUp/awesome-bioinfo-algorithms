A curated collection of classic and modern bioinformatics algorithms — covering sequence alignment, assembly, variant calling, phylogenetics, RNA analysis, protein structure, metagenomics, single-cell, spatial transcriptomics, and gene annotation.

## Categories

| Category | Topics |
|----------|--------|
| **Sequence Alignment** | Smith-Waterman, Needleman-Wunsch, BLAST, BWA-MEM, Minimap2, DIAMOND |
| **Genome Assembly** | de Bruijn Graph, OLC, String Graph, SPAdes, Hifiasm |
| **Variant Calling** | GATK HaplotypeCaller, DeepVariant, Strelka2, Manta |
| **Phylogenetics** | Neighbor-Joining, Maximum Likelihood (RAxML), Bayesian (MrBayes), BEAST |
| **RNA Analysis** | STAR, Salmon, DESeq2, edgeR, WGCNA |
| **Protein Structure** | AlphaFold2, ESMFold, RoseTTAFold |
| **Metagenomics** | Kraken2, MetaPhlAn, HUMAnN, MEGAHIT |
| **Single-Cell** | Scanpy, Seurat, scVI, CellRanger |
| **Spatial Transcriptomics** | STARmap, MERFISH, Visium (10x), SpatialDE |
| **Gene Annotation** | Prodigal, BRAKER, AUGUSTUS, GeneMark |

## Algorithm Entry Format

Each algorithm entry includes:
- **Description** — What it does and why it matters
- **Use Case** — Primary application scenario
- **Complexity** — Time and space complexity
- **Paper** — Original publication DOI link
- **Implementation** — Reference implementation URL
- **Related Tools** — Alternative or complementary tools
- **Tags** — Searchable keywords
