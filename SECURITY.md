| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability / 报告漏洞

We take security seriously. If you discover a security vulnerability, please follow these steps:

我们非常重视安全问题。如果您发现安全漏洞，请按照以下步骤操作：

### How to Report / 如何报告

1. **Do NOT** create a public GitHub issue for security vulnerabilities.
   **不要**为安全漏洞创建公开的 GitHub issue。

2. Send an email to the project maintainers with:
   向项目维护者发送电子邮件，包含：
   - A description of the vulnerability / 漏洞描述
   - Steps to reproduce the issue / 复现步骤
   - Potential impact / 潜在影响
   - Any suggested fixes (if available) / 建议的修复方案（如有）

3. Allow up to 48 hours for an initial response.
   请等待最多 48 小时以获得初步回复。

### What to Expect / 预期流程

- We will acknowledge receipt of your report within 48 hours.
  我们将在 48 小时内确认收到您的报告。

- We will provide an estimated timeline for a fix.
  我们将提供修复的预计时间表。

- We will notify you when the vulnerability is fixed.
  漏洞修复后我们会通知您。

- We will credit you in the release notes (unless you prefer to remain anonymous).
  我们将在发布说明中感谢您（除非您希望保持匿名）。

## Security Best Practices / 安全最佳实践

When contributing to this project:
在为本项目做贡献时：

- Keep dependencies up to date / 保持依赖项更新
- Follow secure coding practices / 遵循安全编码实践
- Review code changes for potential security issues / 审查代码更改以发现潜在安全问题
- Report any suspicious activity / 报告任何可疑活动

Thank you for helping keep this project secure!
感谢您帮助保护本项目的安全！
