## Contributing | 贡献指南

When adding a new changelog:

1. Copy [CHANGELOG_TEMPLATE.md](./CHANGELOG_TEMPLATE.md)
2. Name the file: `YYYY-MM-DD_brief-description.md`
3. Fill in all sections
4. Add to both `en/` and `zh/` directories (if bilingual)
5. Update the main [CHANGELOG.md](../CHANGELOG.md)
